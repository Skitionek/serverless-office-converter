      Check for yourself that nothing is uploaded
      1. Open your browser's developer tools (F12) and go to the Network tab.
      2. Convert a file. Only this page's own files appear, and none carries your document.
      3. Switch the Network tab to Offline (or disconnect from the internet): conversions keep working.
      Are my original files changed?

      Never. The converter only reads them, and results are downloaded. Only if you choose to save results straight into a folder (Chrome and Edge, under “Save into a folder, or watch a folder”) does it write there, and then only new files: when a name is already taken, for example when converting DOCX to DOCX next to the original, the result is called report (converted).docx or report (1).pdf instead.

      How does it work?

      The page runs LibreOffice, the open-source office suite, compiled to WebAssembly, so the same engine that powers desktop LibreOffice converts your files inside this tab. The first visit downloads it once (about 30 MB) and your browser keeps it.

      Not supported: PDF as input, password-protected files, and some rare formats that were left out to keep the download small. It needs a recent desktop browser and about 1 GB of memory.
