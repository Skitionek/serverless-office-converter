    How it works

    The LibreOffice core (Writer, Calc, Impress and Draw import/export filters) is cross-compiled with Emscripten into a single WebAssembly module, built headless without any UI toolkit. A small script drives it through the UNO API (loadComponentFromURL → storeToURL) inside a Web Worker. The first visit downloads the engine once and keeps it in your browser cache.

    Requires a recent Chrome, Edge, Firefox or Safari on a desktop-class device (the engine reserves 1 GB of memory). PDF input and password-protected files are not supported.

    LibreOffice is licensed under the MPL-2.0; this build is compiled from upstream sources plus the size-reduction patches in build/patches/.
